# DT Frontend Challenge

## Overview
This project is a simple frontend webpage built using HTML, CSS, and JavaScript as part of the DT Frontend Intern assignment.

## Features
- Static UI built from HTML and CSS
- Dynamic content using JavaScript
- Local variable to manage state
- JSON object used to update content dynamically

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser

## Dynamic Logic Explanation
A local JavaScript variable (`step`) is used to track the current state.  
On each button click, the content updates dynamically using values from a JSON object.
